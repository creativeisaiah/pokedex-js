# Pokédex JS (Kanto)

A simple Kanto Pokédex built with vanilla **HTML / CSS / JavaScript**.

## What it does
- Displays Pokémon info in a clean UI
- Lets you browse and/or search Pokémon (Kanto / Gen 1 focus)
- Uses JavaScript to load and render data dynamically

## Tech stack
- HTML
- CSS
- JavaScript (vanilla)

## Check it out here
https://creativeisaiah.github.io/pokedex-js/

## Getting started

### Option 1: Download ZIP
1. Click **Code** → **Download ZIP**
2. Unzip the folder
3. Open `index.html` in your browser
